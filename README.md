# checkrange

Check CSV/TSV range tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/checkrange/

## Install / run

```bash
git clone https://github.com/theworker02/checkrange.git
cd checkrange
node src/cli.js
node --test
```
